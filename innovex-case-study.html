AOI 編程工程師的位置,Agent 接下來

元件辨識、ROI 繪製、閾值計算——這三件原本要花 3 到 5 小時人工的事, AI Agent 從一塊參考板自動跑完。換線時間壓進 5 分鐘,操作員 30 分鐘上手。 沒有 CAD,沒有元件庫,沒有 AOI 編程工程師。

它也搞定規則式 AOI 一直卡關的判讀:依工廠合格標準分類 DIP 焊點、從黑電感與石英振盪器的密集字樣中分離真實缺陷、辨識與板材同色的元件、SOD 與 LED 極性。 多維度特徵分析取代 RGB 規則比對。

「一框多測」讓單一 ROI 同時偵測 5 類缺陷:缺件、錯件、反件、損傷、立碑。 1ms / 元件、45 cm²/s 吞吐、檢出 ≥98%。 Agent 隨作業員回饋持續迭代,誤報率下降 80%,越用越準。

The Agent takes the AOI seat

Component identification, ROI drawing, threshold setting — three things that used to take 3–5 hours of manual work. The Agent runs them from a single Golden Board. Changeover collapses to 5 minutes. Operators ramp up in 30. No CAD, no library, no AOI engineer.

It also closes the cases rule-based AOI keeps missing: DIP solder-joint classification to your accept criteria, separating real defects from dense markings on black inductors and crystal oscillators, recognizing components that match the PCB laminate, SOD / LED polarity. Multi-dimensional features replace RGB matching.

One-box multi-detection catches all 5 defect types in a single ROI — missing, wrong, reversed, damaged, tombstoned. 1ms per component, 45 cm²/s throughput, ≥98% detection. The Agent iterates from operator feedback. False calls keep dropping the more you run it — down 80%.
